# Security

Pokémon Survivors is a static, client-side game with no accounts and no backend. Progress lives only in your browser's `localStorage`.

If you find a security issue (for example, a way to run scripts on the site through crafted data), please **don't open a public issue**. Report it privately through [GitHub's private vulnerability reporting](https://github.com/pedrobarretto/pokemon-survivors/security/advisories/new). You'll get a reply as soon as possible.

Gameplay exploits like editing your own save to get more Poké Dollars are not security issues. Feel free to open a regular issue about them.
